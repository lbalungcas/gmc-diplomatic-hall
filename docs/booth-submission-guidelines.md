# Booth Submission Guidelines  
## Youth Innovations Marketplace · Digital Diplomatic Hall

Thank you for exhibiting. Use this checklist so we can build your booth in the **3D Diplomatic Hall** (passport stamps, booth TV, quiz, hearts, and visitor notes).

Submit one package per booth. If something is not ready, mark it **TBC** — we can start with placeholders and swap assets later.

---

## 1. What appears on your booth

| In the hall | What we need from you |
|-------------|------------------------|
| Booth title & category | Official project / innovation name + short category |
| Overview panel | Project summary visitors read when they open the exhibit |
| Stats chips | Optional key facts (numbers + short labels) |
| Links & socials | Website, docs, social profiles |
| Booth TV + poster | Loop video (or YouTube) + a still image for the screen |
| Passport quiz | 2–3 short questions about your innovation |
| Hearts / visitor notes | No extra assets — built into the hall |

---

## 2. Required information (text)

Please send as a Word/Google Doc, PDF, or filled form — English preferred.

### Project identity
- **Booth number** (if already assigned) or preferred placement note  
- **Official project name** (max ~60 characters for the UI)  
- **Short display name** (if different from official name)  
- **Category** (e.g. Innovation, GreenTech, EdTech, Health, Creative)  
- **Organisation / team name**  
- **Country / region**  
- **Age group of youth leads** (for context only; no personal data of minors in public copy)

### Overview (required)
- **Project summary:** 80–150 words  
  - What problem you address  
  - What your solution does  
  - Who it helps  
  - One concrete outcome or goal  
- Keep language visitor-friendly (ministers, partners, youth peers).  
- Do **not** include private phone numbers, home addresses, or hotel/meal logistics in public booth text.

### Optional stats (up to 4)
Examples:
| Value | Label |
|-------|--------|
| 12 | Schools reached |
| 3 | Provinces |
| 2024 | Founded |

### Links (optional but recommended)
- Website or landing page  
- Pitch deck / one-pager (public URL or PDF)  
- Demo or repo (if public)  

Label each link clearly (e.g. “Website”, “One-pager”, “Watch demo”).

### Socials (optional)
- Instagram / Facebook / X / LinkedIn / TikTok / YouTube — **full HTTPS URLs**

### Contact for organisers only (not shown on the public booth unless you ask)
- Lead contact name + email (adult / organisation)  
- Alternate contact  
- Preferred language for follow-ups

## 3. Image guidelines

### A. Booth TV poster / screen still (**required**)
Used as the TV face in the hall and as the video poster.

| Spec | Requirement |
|------|-------------|
| **Aspect ratio** | **16:9** (landscape) |
| **Recommended size** | **1920 × 1080 px** (min 1280 × 720) |
| **Format** | PNG or JPG (PNG preferred if you have text/logo) |
| **Colour** | sRGB; avoid pure black full-bleed if possible |
| **File name** | `booth_XX_screen.png` (e.g. `booth_07_screen.png`) |
| **Max file size** | 3 MB |

**Content tips**
- Clear project name + one strong visual (product, youth in action, illustration)  
- Logo readable at a distance; leave margin from edges  
- High contrast text; no tiny paragraphs on the poster  
- Safe zones: keep critical text/logo inside the centre 80%  

### B. Project logo (**recommended**)
| Spec | Requirement |
|------|-------------|
| Format | PNG with transparent background preferred |
| Size | At least **512 × 512 px** (square) or SVG |
| Variants | Full colour + optional white/mono for dark UI |

### C. Extra gallery images (**optional**)
Up to **4** supporting photos or graphics for future gallery use.

| Spec | Requirement |
|------|-------------|
| Aspect | 16:9 or 4:3 preferred |
| Size | Min 1280 px on the long edge |
| Format | JPG or PNG |
| Consent | Youth faces only with documented consent (see §6) |

## 4. Video guidelines (Booth TV)

Visitors can tap/click the booth TV to watch **with sound**. Silent loops also play in the hall.

### Preferred options (pick one)
1. **Hosted MP4 file** (best for the 3D hall)  
2. **YouTube or Vimeo public/unlisted URL** (we can embed or use as intro)

### MP4 specs (if you send a file)

| Spec | Requirement |
|------|-------------|
| **Aspect** | **16:9** |
| **Resolution** | 1920 × 1080 preferred (min 1280 × 720) |
| **Codec** | H.264 video + AAC audio |
| **Container** | `.mp4` |
| **Length** | **30–90 seconds** ideal (max 3 minutes) |
| **File size** | Under **40 MB** if possible (max 80 MB) |
| **Audio** | Clear voiceover or music; peak levels not clipping |
| **File name** | `booth_XX_tv.mp4` |

**Content tips**
- Hook in the first 5 seconds (who you are + what you solve)  
- Subtitles/captions strongly recommended (burned-in or `.srt`)  
- End card with project name + website  
- No flashing strobe effects; keep volume consistent  

### YouTube / Vimeo
- Link must be **viewable without login** (Public or Unlisted)  
- Same length guidance as above  
- Include the exact URL in your submission pack

## 5. Passport quiz (required)

Each booth can award a **gold passport stamp** when visitors pass the quiz.

| Spec | Requirement |
|------|-------------|
| Questions | **2 or 3** |
| Choices | **2–4** options per question |
| Pass rule | Suggest “pass if 2 of 3 correct” (or 2 of 2) |
| Tone | Fair, educational — not trick questions |

**Example structure**
1. Question text  
2. Option A / B / C (mark the correct one)  
3. Optional one-line explanation for the correct answer (for our internal QA)

---

## 6. Safeguarding, consent & rights

This is a youth-centred Marketplace. Please confirm:

- [ ] All photos/videos of children or young people have **informed consent** (and guardian consent where required).  
- [ ] You have rights to use all logos, music, footage, and graphics you submit.  
- [ ] No confidential personal data (school IDs, private phones, home addresses) appears in public assets.  
- [ ] Content is appropriate for a mixed audience (youth, ministers, partners).  
- [ ] You agree organisers may crop/compress assets slightly for technical fit (name and meaning unchanged).  

If consent is pending, submit text + logo first and send media later.

## 7. How to package your submission

**Folder name:** `Booth_XX_ProjectName` (example: `Booth_07_CleanEnergyHub`)

```
Booth_07_CleanEnergyHub/
├── 01_project-info.docx          (or .pdf / .txt)
├── 02_quiz.docx
├── images/
│   ├── booth_07_screen.png       ← required TV poster
│   ├── logo.png                  ← recommended
│   └── gallery_01.jpg            ← optional
├── video/
│   └── booth_07_tv.mp4           ← or put YouTube URL in project-info
└── rights/
    └── consent-notes.txt         ← brief confirmation of consent/rights
```

**Send via:** the link or email shared by the organising team (TdH / KNH / VEWU partners).  
**Subject line:** `Marketplace booth assets — Booth XX — Project Name`
